TECHLIFT DAILY WEBSITE STARTER

Included:
- Responsive homepage, CSS and JavaScript
- Three original starter guides in /articles
- About, Contact, Privacy Policy and Disclaimer pages
- Reserved ad placements and AdSense placeholders

BEFORE LAUNCH
1. Replace ca-pub-REPLACE_WITH_YOUR_PUBLISHER_ID with your own publisher ID after you have an AdSense account.
2. Follow the exact verification instructions shown in AdSense; the placeholder alone does not connect the site.
3. The contact form is demo-only and does not send messages. Connect a form service or publish a real contact email.
4. Edit the Privacy Policy so it accurately describes your real hosting, cookies, analytics, advertising and consent practices.
5. Edit and fact-check the article drafts, add your own analysis and examples, and publish more genuinely useful content. Do not mass-publish thin or repetitive AI content.
6. Replace reserved ad blocks with real ad units only after approval. Never click your own ads or encourage others to click them.

FREE HOSTING
GitHub Pages can host these static files from a public repository. However, a free hosting subdomain is not guaranteed to be accepted as a standalone AdSense site. Check eligibility for the exact host and URL. A custom domain gives you more control. Blogger is another free option with a Google-hosted AdSense workflow, but this static site would need to be adapted to a Blogger theme.

PUBLISH USING GITHUB PAGES
1. Create/sign in to GitHub.
2. Create a PUBLIC repository, for example techlift-daily.
3. Upload the CONTENTS of this folder to the repository root (not the enclosing folder).
4. Open repository Settings > Pages. Select deployment from the main branch and root folder, then save.
5. Wait for the URL shown in Settings > Pages and test every page on mobile and desktop.
6. Before AdSense, check the exact domain/host eligibility. Consider a custom domain for long-term control.

ADSENSE CHECKLIST
1. Publish a working, public website.
2. Improve and expand original content; ensure navigation works.
3. Publish accurate About, Contact, Privacy Policy and Disclaimer pages.
4. Visit https://adsense.google.com/start/ and follow current instructions.
5. Add the eligible site in AdSense, install the exact verification code, verify ownership and request review.
6. Wait for Google's decision. Approval is not guaranteed; review can take days or, in some cases, a few weeks.
7. After approval, enable Auto ads or create ad units and replace the reserved ad placements.
